# ROSMASTER CubeBot

Панель управления Yahboom ROSMASTER M3 Pro, работающая на порту **8090**. Снимок исходников `~/CubeBot` с робота от 13 ноября 2026 года. [Explorer 3.0](https://github.com/vladromenko/explorer-3.0) — отдельный проект Homebrain для записи демонстраций, обучения ACT и исследования коррекций.

| Страница | Что доступно |
| --- | --- |
| `/` | Камера, шасси и рука с клавиатуры или геймпада, координаты кисти, заряд, STOP, зеркало SO-101 Leader и миссия с кубиком |
| `/tutorial` | Инструкции по панели |
| `/experiments` | Запуск экспериментов и результаты |
| `/exp-docs` | Интерактивная документация с телеметрией, кинематикой, глубиной и навигацией |

Миссия CubeBot ищет жёлтый кубик, захватывает его, едет к коробке, кладёт кубик внутрь и извлекает его. Код миссии и симуляции находится в `cubebot/mission.py` и `cubebot/sim.py`. Нативный мост STM32 ↔ ROS 2 находится в `rosmaster/`.

## Быстрая проверка без робота

Python 3.12, из корня репозитория.

```bash
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt pytest
python -m pytest -q
python -m scripts.sim_run --seed 1 --quiet
```

Коррекция одометрии по лидарам (ICP) в штатной конфигурации робота выключена. Тест `test_fused_odometry_beats_wheels_under_slip` включает её явно, чтобы проверить коррекцию при проскальзывании колёс.

## Эксперименты

| Код | Эксперимент |
| --- | --- |
| E1 | Следование за выбранным человеком, удержание дистанции и повторный захват цели |
| E2 | Распознавание жестов и испытания с контролем контекста |
| E3 | Построение карты со SLAM Toolbox, обход фронтиров и движение к целям через Nav2 |
| E4 | Поиск, захват и доставка выбранного предмета |
| E5 | Помощник с выбором получателя и передачей предмета |

Код в `cubebot/exp/`, общие параметры в `cubebot/exp/settings.py`. Сохранённые модели MediaPipe и EfficientDet находятся в `models/`. Результаты новых испытаний записываются в `results/<код>/trials.jsonl` и AVI. Карты сохраняются в `maps/`, точки — в `data/waypoints.json`. Рабочие карты и записи камеры хранятся в локальном снимке робота.
